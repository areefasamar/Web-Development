# 📄 AI Resume & ATS Evaluator
This project is an AI-powered Applicant Tracking System (ATS) Evaluator designed to help candidates optimize their resumes for modern hiring workflows. Built during the GDG Kolachi Build with AI Workshop, it uses Large Language Models to bridge the gap between a candidate's experience and specific job descriptions.

## 🚀 Live Demo & Video
Live Web App: [Click here](https://atsscoreevaluator.netlify.app/)

## ⚠️ The Problem
Most job seekers struggle to pass initial ATS filters because their resumes lack the specific keywords or formatting required by automated systems. This tool provides an "insider look" at how a resume measures up against a job post before the user ever hits "Apply."

## ✨ Key Features
Semantic Matching: Goes beyond simple keyword counting to analyze the context of your experience using Google's AI models.

ATS Score Generation: Provides a percentage match score based on skills, experience, and industry-standard keywords.

Gap Analysis: Specifically identifies which technical or soft skills are missing from the resume that are present in the job description.

Optimization Suggestions: Offers actionable feedback on how to rephrase bullet points for better impact and clarity.

## 🛠️ Technical Stack
LLM Integration: Powered by Gemini via Google AI Studio for deep text analysis.

Document Parsing: Integrated PDF/Text extraction to handle real-world resume formats.

Prompt Engineering: Utilizes custom system instructions to act as a "Senior Technical Recruiter" for highly accurate feedback.

## 📊 How it Works
Upload: Drop your resume in PDF or Text format.

Paste: Add the Job Description you are targeting.

Analyze: The AI compares the two, looking for overlaps in tech stacks, certifications, and responsibilities.

Improve: Receive a detailed report with a score and a list of "Missing Keywords" to add.
